古堅南FC PKチャレンジ Ver.1.0

【遊び方】
1. index.html をブラウザで開く、またはGitHub Pagesへアップロードします。
2. 「ゲームスタート」から選手を選びます。
3. ゴール内の好きな場所をタップして、5本勝負に挑戦します。

【主な機能】
・古堅南FCメンバー選択
・PK 5本勝負
・GKランダムAI
・端末内ランキング
・選手追加・編集・削除
・選手写真、チームエンブレム設定
・スマホ、タブレット対応
・PWA、オフライン対応

【重要】
選手写真・名簿・ランキングはブラウザの端末内保存（localStorage）です。
ブラウザデータを消去すると記録も消えるため、正式版ではバックアップ機能の追加を推奨します。
既存の古堅南FC成績管理アプリには上書きせず、別リポジトリまたは別フォルダで公開してください。
